## Project

Joolomee is my personal portfolio and services website, bringing brand identity, selected work and professional contact into one experience. Its central idea — **“Remember me, Joolomee.”** — connects my creative direction with the way visitors discover my work.

The goal is to help recruiters and potential collaborators understand my design practice, explore projects across disciplines and find a clear route to contact.

## What this project demonstrates

| Skill | Project evidence |
| --- | --- |
| Brand communication | A consistent brand voice, positioning and service offering across the portfolio. |
| UX and information architecture | Dedicated Work, Services and About sections, with contact entry points. |
| Content modelling | Structured project entries with categories, tags and visual references. |
| Frontend technology | Next.js 14, React 18, TypeScript and Tailwind CSS in the project stack. |
| Motion tooling | Framer Motion and Lenis included for animation and scrolling. |
| Internationalisation | Content dictionaries for English, Portuguese, Spanish, French, German, Italian and Dutch. |
| Interaction design | A five-question discovery quiz with four brand-journey profiles. |
| Delivery workflow | Build and verification scripts, including portfolio and SEO checks. |
